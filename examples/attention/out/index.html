Scaled Dot-Product Attention

Written for: Engineering undergraduates who know basic linear algebra (vectors, matrices, dot products) but have not studied transformers.

1The idea

Attention lets each query look at every key and decide how much of each value to copy. We take the dot product of a query with each key to get a raw score, optionally divide by √dk, and run a softmax so the scores become weights that sum to 1. The output for that query is then the weighted average of the value rows.

Why it matters. This one equation is the core of the transformer: it is how every token gathers information from every other token, and the 1/√dk factor is what keeps that gathering stable as dimensions grow.

From the paper · Eq. (1)
Attention(Q, K, V) = softmax(QKT / √dk) V

2Symbols

SymbolMeaning
Qmatrix of queries, one row per query, each of dimension dk
Kmatrix of keys, one row per key, each of dimension dk
Vmatrix of values, one row per key, each of dimension dv
dkdimension of the queries and keys (number of columns of Q and K)
dvdimension of the values (number of columns of V)
QKTmatrix of raw dot-product scores, entry (i, j) = qi · kj
softmaxapplied to each row of scores, turning them into non-negative weights that sum to 1

3How it works

  1. Form the raw scores S = QKT: each entry is the dot product of one query with one key.
  2. If scaling is on, divide every score by √dk; if off, leave the scores as they are.
  3. Apply softmax to each row of scores to get the attention weights, which are non-negative and sum to 1 per row.
  4. Multiply the weights by V: each output row is the weighted sum of the rows of V.

    5Guided explorations

    Exploration 1Equal scores give a uniform average

    Change
    Set Q to [[1,0]], K to [[1,0],[1,0],[1,0]] and V to [[1,0],[0,1],[1,1]], with scaling on.
    Observe
    All three raw scores are 1, so after softmax every weight is 1/3 and the output is the plain average of the three value rows, [0.667, 0.667].
    Why
    Softmax of equal scores is uniform, and the output is the weighted sum of the rows of V, so equal weights mean an unweighted mean.

    Exploration 2One dominant score concentrates the weight

    Change
    Keep Q and V, but set K to [[1,0],[0,1],[0,1]] so the first key matches the query and the others do not.
    Observe
    The first weight jumps to about 0.576 while the other two drop to about 0.212 each, and the output moves toward the first value row [1, 0].
    Why
    A larger dot product for key 1 makes its score larger, and softmax exponentiates scores, so a modest score gap becomes a large weight gap.

    !Keep in mind

    The scaling factor only matters when the scores are large: with the tiny integer vectors used here, turning scaling off changes the weights only slightly. The paper's point is about large dk, where unscaled dot products grow in magnitude and push softmax into regions with extremely small gradients.

    From the paper
    Attention(Q, K, V) = softmax(QKT / √dk) V
    “We compute the dot products of the query with all keys, divide each by √d_k, and apply a softmax function to obtain the weights on the values.”
    “Attention(Q, K, V) = softmax(QK^T / √d_k) V”
    “To counteract this effect, we scale the dot products by 1/√d_k.”
    Our example / simplification
    • The demo uses one or two queries and three keys with tiny integer entries; the paper uses full sequences of learned vectors.
    • Q, K and V are typed in by hand rather than produced by learned projection matrices.
    • The softmax is computed in plain floating point with no numerical stabilisation tricks beyond subtracting nothing, since the demo scores are small.
    • The scaling toggle is an on/off switch for the 1/√dk factor; the paper always applies it.

    This is a small illustrative demo; it does not reproduce the paper's experimental results.
