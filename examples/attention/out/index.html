From the paper

Scaled Dot-Product Attention

Attention Is All You Need · §3.2.1 · Eq. (1)

Written for: Engineering undergraduates who know basic linear algebra (vectors, matrices, dot products) but have not studied transformers.

The idea

A query asks a question; every key is compared with it by a dot product, and the resulting scores say how relevant each value is. Softmax turns those scores into weights that sum to one, and the output is the weighted average of the value rows. Dividing the scores by √dk keeps them from growing so large that softmax becomes nearly one-hot.

Why it matters. This single equation is the core of the transformer: it is how every token gathers information from every other token, and the 1/√dk factor is what keeps that gathering trainable as dimensions grow.

From the paper · Eq. (1)
Attention(Q, K, V) = softmax(QKT / √dk) V

Symbols

SymbolMeaning
Qmatrix of queries, one row per query, each row of length dk
Kmatrix of keys, one row per key, each row of length dk
Vmatrix of values, one row per key, each row of length dv
dkdimension of each query and key vector
dvdimension of each value vector
QKTmatrix of raw dot-product scores, entry (i, j) = qi · kj
softmaxapplied to each row of scores, turning it into non-negative weights that sum to 1
√dkthe scaling divisor that counteracts large dot products

How it works

  1. Form the raw scores S = QKT: each entry is the dot product of one query with one key.
  2. Divide every score by √dk (this is the scaling step; it can be switched off).
  3. Apply softmax to each row of scores, giving attention weights A that are positive and sum to 1 per row.
  4. Multiply the weights by V: output row i = Σj Aij vj, a weighted average of the value rows.

    Guided explorations

    Exploration 1: Equal scores versus one dominant score

    Change
    Set the query to [1, 1] and the keys to [[1, 1], [1, 1], [1, 1]] so all three scores are identical, then set the keys to [[1, 1], [0, 0], [0, 0]] so the first key dominates.
    Observe
    With equal scores the weight row is [0.333, 0.333, 0.333] and the output is the plain average of the three value rows. With one dominant key the weight row moves toward [1, 0, 0] and the output moves toward that key's value row.
    Why
    Softmax is monotone in the scores, so the largest score always gets the largest weight; when all scores are equal the exponentials cancel and the weights are uniform.

    Exploration 2: Turning the 1/√dk scaling off

    Change
    Keep the same Q, K and V but switch the scaling toggle off, so the raw dot products are fed straight into softmax.
    Observe
    The largest weight grows and the smaller weights shrink: the weight row becomes more peaked, and the output moves closer to the dominant value row.
    Why
    Without the 1/√dk divisor the scores are √dk times larger, and softmax amplifies differences in its inputs, so large scores push the distribution toward one-hot.

    Keep in mind

    The demo uses one query and three keys with dk = 2 so the numbers fit on screen; the paper applies the same equation to whole sequences of queries at once, with dk typically 64, and the scaling matters most exactly there, where unscaled dot products grow large.

    Our example / simplification
    • The demo fixes one query row and three key/value rows with dk = 2 and dv = 2; the paper uses full matrices of many queries and larger dimensions.
    • The temperature slider is not in the paper; it is an extra knob that divides the scores before softmax so the sharpening effect can be seen continuously.
    • The demo does not implement multi-head attention, masking, positional encodings or any training; it evaluates Eq. (1) once on the numbers you type.
